# Simple Pan

基于 Jetpack Compose + Room + MVI 的简易个人网盘 Android 客户端。

> 工程训练营项目 · 三周开发周期 · 开发中

---

## 项目状态

🚧 **开发中** —— 当前阶段：阶段零（基础设施准备）

## 技术栈

- **语言：** Kotlin
- **UI：** Jetpack Compose
- **架构：** MVI + 分层架构
- **数据库：** Room
- **异步：** Kotlin Coroutines + Flow
- **依赖注入：** Hilt
- **导航：** Navigation Compose
- **日志：** Timber
